곱셈 공식 완벽 정리

중학교에서 배우는 대표적인 곱셈 공식은 다음과 같습니다.

  • (a + b)2 = a2 + 2ab + b2
  • (a - b)2 = a2 - 2ab + b2
  • (a + b)(a - b) = a2 - b2
  • (x + a)(x + b) = x2 + (a + b)x + ab

예: (x + 3)2 = x2 + 6x + 9 입니다.
